\begin{abstract}
    Let $\mathcal C= \{k_1<k_2 < \cdots\}$ be Cantor set of integers, that is a set of integers with restricted digits modulo a base $b$, and suppose $0$ is one of the restricted digits.  
We show that  
\begin{equation}
\liminf_N \Expectation_{n\in [N]}  m(A\cap T^{-k_n} A \cap \cdots 
        \cap T^{-\ell k_n} A )>0. 
\end{equation}
This is an extension of the IP Ergodic Theorem of Furstenberg and Katznelson, 
and a partial extension of recent work of Kra and Shalom. 
In particular, this implies that for any subset of integers $A$ of positive upper Banach density, 
there is a set $B$ of integers $n$ of positive lower Banach density 
such that $A$ contains an $\ell+1$ term progression, with step size $k_n$, where $n\in B$.    
\end{abstract}
